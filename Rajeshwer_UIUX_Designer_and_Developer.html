UX Problem-Solving Scenarios

MySecureME EMM

Problem: Mapping established configuration profiles/policies across bulk device enrollments to specific users and groups.

Solution: Designed an "Assigned Policies" experience in User Management, allowing admins to search and stack/prioritize multiple configuration profiles with feature-level controls.

Orion – Enterprise Data Management

Problem: Inconsistent duplicate data across 5 modules without a clear workflow for error resolution.

Solution: Combined error identification and resolution into a guided workflow, eliminating screen context switching.

EHR Application

Problem: Providers were forced to navigate across 9+ modules (Messaging, History, Lab Results, etc.) to gather patient context during appointment requests.

Solution: Designed an AI-assisted contextual workflow surfacing only relevant patient data for specific appointment contexts, cutting out visual clutter.

SplashBI Enterprise SaaS

Problem: Moving from high-level charts to granular table data caused users to lose analytical context.

Solution: Designed a side Inspection Panel that opens upon selecting chart elements to preserve visual analytical context.
